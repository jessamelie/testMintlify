## Prérequis

Avant de commencer, assurez-vous de disposer de :

- Node.js (version 18 ou supérieure recommandée) et `npm`
- La CLI Mintlify (`mint`) pour prévisualiser la documentation en local

## Lancer l'application React

<Steps>
  <Step title="Installer les dépendances">
    Installez React et Vite depuis la racine du projet :

    ```bash
    npm install
    ```
  </Step>
  <Step title="Démarrer le serveur de développement">
    Lancez le serveur local Vite :

    ```bash
    npm run dev
    ```
  </Step>
  <Step title="Générer le build de production">
    Vérifiez et compilez le bundle statique dans `dist/` :

    ```bash
    npm run build
    ```
  </Step>
</Steps>

## Prévisualiser la documentation Mintlify

Depuis la racine du projet (où se trouve `docs.json`), exécutez :

```bash
mint dev
```

<Tip>
  Si `mint` n'est pas installé globalement, installez-le avec `npm i -g mint` ou utilisez `npx mint@latest dev`.
</Tip>
