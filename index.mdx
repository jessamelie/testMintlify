**Ma To-Do** est une application web React + Vite qui permet de gérer une liste de tâches quotidienne avec une palette pastel douce et une persistance locale dans `localStorage`.

## Structure du projet

Le dépôt regroupe le code source de l'application React et sa documentation Mintlify au même endroit :

```text
testMintlify/
├── docs.json                  # Configuration du site Mintlify
├── index.mdx                  # Page d'accueil de la documentation
├── quickstart.mdx             # Guide de démarrage rapide
├── features.mdx               # Détails CRUD, persistance et palette pastel
├── index.html                 # Point d'entrée HTML de Vite
├── package.json               # Scripts et dépendances React / Vite
├── vite.config.js             # Configuration Vite
└── src/
    ├── main.jsx               # Montage de l'application React
    ├── App.jsx                # État global, filtres et opérations CRUD
    ├── constants/palette.js   # Définition des 5 catégories pastel
    ├── components/
    │   ├── TodoForm.jsx       # Création d'une tâche
    │   ├── TodoItem.jsx       # Affichage, édition en ligne et suppression
    │   └── TagSelector.jsx    # Sélecteur de catégorie pastel
    └── styles/index.css       # Feuille de styles pastel
```
