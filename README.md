# Ma To-Do

Application simple de to-do list en React + Vite avec une palette pastel douce, opérations CRUD complètes (`localStorage`), et documentation intégrée avec [Mintlify](https://mintlify.com).

## Lancer l'application

```bash
npm install
npm run dev
```

Pour compiler le build de production :

```bash
npm run build
```

## Prévisualiser la documentation Mintlify

```bash
mint dev
```

Pour vérifier la validité de la documentation :

```bash
mint validate
```
